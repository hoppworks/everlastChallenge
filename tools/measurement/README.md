# Messwerkzeuge

Aktuelle Auswertungs- und Messkommandos stehen unter
[Entwicklerwerkzeuge](../../docs/tooling.md). Die veröffentlichten Ergebnisse
und ihre Grenzen beschreibt der [aktuelle Vergleich](../../docs/comparison.md).

Patch-/JSON-Paare in diesem Ordner sind isolierte Implementierungsartefakte,
keine Funktionen oder Messbelege der aktuellen App. Sie dürfen ausschließlich
auf ihre jeweils gebundene Quellbasis angewendet werden.
